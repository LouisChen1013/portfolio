# Portfolio Website

A modern, responsive personal portfolio website built with React and Vite.

## 🚀 Live Demo

[View Portfolio](https://louischen1013.github.io/portfolio/)

## ✨ Features

- **Responsive Design:** Optimized for various screen sizes and devices.
- **Multi-language Support:** Seamless switching between English (EN) and Chinese (ZH) using `react-i18next`.
- **Dynamic Theming:** Custom `ThemeProvider` with support for multiple color schemes (Light, Almond, Blue, Charcoal).
- **Interactive Elements:**
  - Typewriter effect in the hero section.
  - Comprehensive project showcase with detailed views.
- **Performance:** Optimized build using Vite.

## 🛠 Tech Stack

- **Framework:** React 19 (RC)
- **Build Tool:** Vite
- **Styling:** React Bootstrap, Custom CSS
- **Internationalization:** react-i18next
- **Deployment:** GitHub Pages

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/louischen1013/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

### Development

Start the development server:

```bash
npm run dev
```

### Build

Create a production build:

```bash
npm run build
```

### Linting

Run the linter:

```bash
npm run lint
```

## 🚀 Deployment

The project is configured to be deployed to GitHub Pages using:

```bash
npm run deploy
```
